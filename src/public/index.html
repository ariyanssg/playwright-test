How an audit runs

  1. Collect URLs

    From Google results, sitemaps, a site crawl, backlinks or a list you upload.

  2. Render every page

    A real Chromium visit records the status code, redirects and what the page actually says.

  3. Compare with Google

    Optionally checks opening hours, phone, website and service links against the Google listing.

  4. Export the evidence

    Excel, CSV and JSON reports with the reason behind every verdict.

Reading the verdicts

  • Hard 404

    The server says the page is missing.

  • Soft 404

    Answers 200, but reads like an error or dumps visitors on the homepage.

  • Redirected

    Moves to a working page. Worth a look, not broken.

  • Healthy

    Loads and reads like a real page.

Search and backlink sources add coverage; no provider guarantees a complete list of indexed pages.

Connections

Imports, sitemaps and the site crawl work with no account. Connect a provider when an audit needs more.

How to enable a connection

Add the provider credentials to the local .env file, then restart the dashboard. Credentials are never entered or shown in this interface.

Authorized redirect URI for your Google Cloud OAuth client (Credentials → your Web client → Authorized redirect URIs). Search Console and Business Profile both use it. Open the dashboard at , not localhost: Google treats them as different addresses.

Google search results
The local browser works without a key. For an API, set SERPER_API_KEY (Serper, the cheapest) or SEARCHAPI_API_KEY. With both set, Auto uses Serper and falls back to SearchApi.
Google Search Console
GOOGLE_CLIENT_ID and GOOGLE_CLIENT_SECRET, then connect your account.
DataForSEO backlinks
DATAFORSEO_LOGIN and DATAFORSEO_PASSWORD
Google Places (hours and public profile)
GOOGLE_MAPS_API_KEY — an API key, not the OAuth client above. Enable Places API (New) in Google Cloud, and make sure the key has no IP or HTTP-referrer restriction that blocks this machine. Use Test key to confirm Google accepts it.
Google Business Profile (profile you manage)
GOOGLE_CLIENT_ID and GOOGLE_CLIENT_SECRET, then connect the Google account that manages the restaurant. Google also has to approve Business Profile API access for your Cloud project; until it does, the quota is 0 and loading locations fails.

A key that is present is not always a key that works. If a profile audit returns no Google values, test the key here: Google’s own reason for rejecting it is shown in full.
