Reading the verdictsWhat each page outcome means
  • Hard 404

    The server says the page is missing. Redirect it or remove links to it.

  • Soft 404

    Answers 200, but reads like an error or sends visitors to the homepage.

  • Redirected

    Moves to a working page. Worth a look, not broken.

  • Timed out · Blocked · Errors

    The page could not be read. Open it yourself; it is not counted as broken.

  • Healthy

    Loads and reads like a real page.

Search and backlink sources add coverage; no provider guarantees a complete list of indexed pages.

Imports, sitemaps and the site crawl need no account. Connect a provider when an audit needs more.

How to set up a connection

Add the provider credentials to the local .env file, then restart the dashboard. Credentials are never entered or shown in this interface.

Authorized redirect URI for your Google Cloud OAuth client (Credentials → your Web client → Authorized redirect URIs). Search Console and Business Profile both use it. Open the dashboard at , not localhost: Google treats them as different addresses.

Google search results
Set SERPER_API_KEY (Serper, the cheapest) or SEARCHAPI_API_KEY. With both set, Auto uses Serper and falls back to SearchApi. The desktop version can also use a local browser without a key.
Google Maps listing (hours and business profile)
SERPER_API_KEY reads the public Google Maps listing for about 3 credits per restaurant. GOOGLE_MAPS_API_KEY (Places API New) is the fallback; make sure no IP or HTTP-referrer restriction blocks the server, and use Test key to confirm Google accepts it.
DataForSEO backlinks
DATAFORSEO_LOGIN and DATAFORSEO_PASSWORD
Google Search Console
GOOGLE_CLIENT_ID and GOOGLE_CLIENT_SECRET, then connect your account. Desktop version only.
Google Business Profile (profile you manage)
The same OAuth client, then connect the Google account that manages the restaurant. Google must also approve Business Profile API access for the Cloud project. Desktop version only.
